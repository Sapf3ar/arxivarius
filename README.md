# LLM помощник для чтения статей Arxivarius

Наше решение - сервис для ускорения анализа статей.

## Проблема
В статьях часто представлены термины, объяснения которых не даны или даны в зависимых статьях. Научный сотрудник при чтении статьи зачастую тратит много времени и сил на поиск информации по той или иной термин.

## Идея
Создать мультиагентный помощник для обзора статьи, у которого будет доступ к расширенной базе терминов из учебников, а также возможность искать необходимую информацию в зависимых статьях.

## Описание решения
В основе лежит мультиагентная среда, которая имеет следующие инструменты для уточнения информации по статье:
- поиск информации по RAG образуемой статьей
- поиск информации по RAG учебников по математике, ML и DL, алгоритмов
- возможность получать текстовую информацию из зависимых статьей
- возможность генерировать псевдокод для лучшего описания вопроса
