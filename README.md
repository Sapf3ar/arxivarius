## Testing Process

The testing process for the functionalities in `main.py` was structured as follows:
1. **Unit Tests**: All key functionalities were tested using pytest, covering various scenarios and edge cases. Examples include validating the initialization of session keys and ensuring that file uploads are handled correctly.

2. **Integration Tests**: Tests ensuring the WorkFlow interacts appropriately with external services were added.

3. **Edge Cases**: Tests were included for edge cases that could affect the application's behavior, such as invalid input formats.

4. **Documentation**: This document logs the steps taken during the testing process and outlines the criteria for success.
